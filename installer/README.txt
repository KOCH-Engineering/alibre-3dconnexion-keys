KOCH 3Dconnexion Keys - add-on for Alibre Design
================================================
Developed by KOCH Engineering (Henrik J. Koch, Denmark)
Built with Claude (Anthropic).
https://www.linkedin.com/in/henrikjkoch/
https://github.com/KOCH-Engineering/alibre-3dconnexion-keys

Choose what the 12 LCD keys of a 3Dconnexion SpaceMouse Enterprise, the
12 keys of a 3Dconnexion Keyboard Pro and a radial menu on the MENU button of
any SpaceMouse (also the Compact) do in Alibre Design - with names and icons,
and one layout per Part, Assembly, Sketch and Drawing that follows the active
Alibre window automatically.

GETTING STARTED
1. Start Alibre Design and open a part.
2. Click  Add-on > 3Dconnexion > 3Dconnexion keys...
3. Choose a tab (Part / Assembly / Sketch / Drawing) and a device
   (SpaceMouse Enterprise, Keyboard Pro or Radial menu).
4. Click a key, type part of a command name (e.g. "fillet") and press Enter.
5. Click "Save to devices".

You don't have to make macros in the 3Dconnexion app: the add-on creates the
macros, names, icons and key assignments in 3DxWare for you.

Every Alibre ribbon command works, also without a keyboard shortcut: the
add-on clicks the command in Alibre's ribbon itself. If a command is not
available in the active window, you hear a beep and see a short message.

RADIAL MENU
Press the MENU button (left button on the SpaceMouse Compact): 8 functions
pop up around the mouse pointer. Click one, or tilt the cap towards it.

REQUIREMENTS
- Alibre Design (64-bit), tested with version 29
- 3Dconnexion 3DxWare 10 with a SpaceMouse Enterprise and/or Keyboard Pro
  for the keys; any SpaceMouse for the radial menu

FILES
- Add-on:    C:\ProgramData\Alibre AddOns\KochSpaceMouse
- Settings:  %APPDATA%\Koch Engineering\SpaceMouse
- 3DxWare profile backups: %APPDATA%\3Dconnexion\3DxWare\Cfg\bak
- Log:       %LOCALAPPDATA%\Alibre AddOns\KochSpaceMouse\addon.log

UNINSTALL
Windows Settings > Apps > KOCH 3Dconnexion Keys (Alibre add-on).
Your settings are kept; the keys go back to the 3DxWare defaults.
